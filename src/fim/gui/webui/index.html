Structure

initial conditions (starting frequencies)

Simulates one ancestral population of size N×d forward (no migration) until its own heterozygosity stabilizes, then splits it into d demes. Can take real time for a large N or d.

Each cell is one deme's starting allele frequencies at one locus, written as alleleId:frequency pairs (e.g. 0:0.6,1:0.4); each cell's own frequencies must sum to 1.

loci
locus IDlength
convergence statistic(s)

Not a `SimulationParams` field — the batch's own worker-process count (design §0.5, H5). Defaults to this machine's own CPU count.
