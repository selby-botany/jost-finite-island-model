Desktop app guide

This guide covers the fim desktop app (fim-gui). It assumes you know the finite island model and differentiation statistics. It records what this implementation does, which conventions it uses, and where each control lives. For the model itself, start with the introduction to the finite island model.

In the app, open this guide with Help in the left rail or Help > Desktop help. Press F1 for help on the focused field or the current screen.

Before you compare with the literature

Read implementation conventions before you compare a result with a published value. Four conventions most often explain an apparent disagreement:

  • N counts individuals per deme; the engine uses N×ploidy gene copies.
  • The scalar m is the fraction of a deme's parents drawn from the other d−1 demes, not a redraw from all d demes.
  • A generation is migrate, then drift, then mutate.
  • Generation 0 is a Dirichlet prior (or explicit p0), not a sampled population.

Open documents

The tab bar below the title lists open configurations, runs, and studies. Each tab keeps its own screen and history. Switching tabs does not stop work in another tab.

  • Opening a result that is already open selects its existing tab. A new configuration always starts as a separate draft.
  • Open tabs are held in memory for this window; they are not restored after a restart. Saved results are unaffected.
  • Close a tab with its ×, File > Close tab, or Delete while the tab has focus. A configuration with unsaved changes asks whether to save, discard, or keep it. An active run, saved run, or sweep offers the appropriate pause or stop action. Closing a tab never deletes saved results.
  • Right-click a tab for Close other tabs and Close all results. Close all results closes completed run and sweep-result tabs, not configurations or saved runs. Unsaved or active tabs use the usual close dialog one at a time: Keep skips that tab; Escape cancels the rest of the bulk close.
  • With more than 12 tabs open, a notice offers Close all results. This is a reminder, not a limit.

Network access and reproducibility

The app uses the same simulation code and results/ folder as the fim command line. A run started in the app produces the same report.json and trajectory.tlog, byte for byte, as the same configuration and seed run from the terminal; see reproduce a run.

The only network access is Help > Check for updates, which is explicit. Help pages are bundled with the app and work offline. Links to source code and to documents that are not bundled open on GitHub in your browser.
